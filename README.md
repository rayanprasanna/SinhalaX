# SinhalaX — Sinhala Keyboard

Fast, private Singlish → Sinhala keyboard for Android (Kotlin + Jetpack Compose).

## Run it
1. Open this folder in Android Studio and let Gradle sync.
2. Run the `app` configuration on a phone or emulator.
3. Follow the in-app setup: **Enable SinhalaX** → **Select SinhalaX**.
4. Type `kohomadha` and press space → කොහොමද

Tests: `./gradlew :core:engine:test :core:prediction:test`

## Modules
| Module | What it is |
|---|---|
| `:core:engine` | Pure Kotlin Singlish engine (`SinglishScheme` table + `SinglishTransliterator`). No Android, unit-tested. |
| `:core:prediction` | Pure Kotlin: `Lexicon` (compact 100k-word dictionary), `SinglishFuzzer` (likely misspellings), `Predictor` (suggestions + auto-correct), `UserDictionary` (learned words). Unit-tested. |
| `:app` | IME service, keyboard UI, companion app. |

## App structure (`app/src/main/java/dev/valhalla/sinhalax`)
- `ime/SinhalaXImeService.kt` — the input method; hosts Compose; clipboard listener.
- `keyboard/KeyboardController.kt` — all typing logic (composing buffer, shift, modes, enter actions, cursor, delete).
- `keyboard/KeyboardUi.kt` — keyboard UI (suggestion strip, keys, emoji/kaomoji, clipboard) + `KeyboardPreview`.
- `keyboard/KeyboardLayouts.kt` — letter and symbol layouts.
- `keyboard/KeyboardTheme.kt` — 7 built-in themes (incl. animated RGB).
- `data/` — DataStore settings + on-device clipboard history.
- `ui/` — onboarding, Home, Themes, Settings, Guide, Privacy.

## v0.1 features
- Singlish phonetic typing with live Sinhala preview + alternatives (න/ණ, ල/ළ, ස/ෂ) + "keep English" option
- English layout with auto-capitalisation, symbols (2 pages, incl. රු)
- Rakaransaya / yansaya (ක්‍ර, ද්‍ය), clean delete of joined letters
- Swipe space to move cursor, hold delete to repeat, long-press for numbers/symbols
- Smart enter key (search / send / go / done / newline)
- Emoji + kaomoji panel, clipboard history (skips passwords & sensitive clips)
- Password fields: English only, no preview, nothing captured
- 7 themes with live preview; height, text size, bottom padding, hints, number row, sound, vibration
- Auto-generated "How to type" guide with a live converter
- Keyboard never goes online (INTERNET is used only by the theme store, from v0.3)

## Dictionary
`app/src/main/assets/dict/si_words.txt` (top 100,000 words, `word<TAB>frequency`) is generated by
`tools/build_dictionary.py` from `verified_word_list_200K.si` in
https://github.com/nlpcuom/Word-Frequency-List-for-Sinhala (Fernando & Dias, University of Moratuwa, ICON 2021).
**That repository states no licence. Get written permission from the authors before publishing**, or rebuild
the asset from another source with the same script.

## Smart suggestions (v0.2)
- Suggestions + completions while typing (`kohom` → කොහොමද)
- Singlish auto-correct on space/punctuation/enter: d→ද, t→ත, n→ණ/ං, l→ළ, s→ශ/ෂ, short→long vowels,
  ae→ඇ, nd/ng/mb→ඳ/ඟ/ඹ, dh→ධ, b→භ. Rare corpus spellings are replaced only by words ≥50× more common.
- Backspace right after an auto-correction undoes it and remembers your spelling
- Learned words (on device, `files/learned_words.tsv`), viewable/deletable in Settings; never learned in
  password or incognito fields
- Settings: Dictionary suggestions, Auto-correct, Learn my words

## Theme store (v0.3)
Themes screen → **Built-in · Backgrounds · Sounds**. Data comes from the public Audio Hub API at
`https://apps.zentiumdev.com/audiohub` (`StoreApi.BASE_URL`); no new libraries (HttpURLConnection + org.json).
- **Backgrounds**: `GET /backgrounds`, `/background-categories`. Thumbnails are cached in `cacheDir`; the chosen
  image is downloaded to `files/store/` and drawn behind the keys. Keys turn translucent and labels use the
  image's `keyTextColor`. Picking a built-in theme removes the background.
- **Sounds**: Audio Hub audios with category **`Keyboard Sounds`** (`GET /audios?category=Keyboard%20Sounds`).
  Upload short click sounds (under ~150 ms, mp3/ogg/wav) in the Audio Hub admin with exactly that category.
  The chosen sound is downloaded and played with `SoundPool`; volume slider included.
- The keyboard service never touches the network; it only reads the downloaded files.

## Studio (v0.4.1)
New **Studio** tab (Fancy text · FM converter · Stickers) and two new keyboard buttons (**Aa**, sticker).

- **Fancy text** (`core/engine/FancyText.kt`): 19 Unicode styles (bold, script, gothic, outline, bubbles,
  squares, wide, small caps, strikethrough, upside down …) plus frames that also wrap Sinhala. In the
  keyboard, **Aa** picks a style and English letters/digits are typed in it (never in password fields).
- **FM converter** (`core/engine/FmConverter.kt`): Unicode ⇄ FM Abhaya (FM family). Kotlin port of the
  MIT-licensed converter from legacy-fonts-to-unicode / Pandukabhaya (akuruAI) / UCSC LTRL; notices kept in
  the file header. Verified identical to the original on 20,009 dictionary words; 20,008 round-trip exactly.
- **GIFs · Stickers · Memes (KLIPY)** (`store/KlipyApi.kt`, `ime/StickerSender.kt`, `keyboard/StudioPanels.kt`):
  tabs in the emoji panel with Recent / Trending / category chips. Tapping sends the item straight into the
  chat with Android's rich-content API in the best format the app accepts (GIFs as GIF; animated stickers as GIF so WhatsApp plays them instead of making a still
  "Custom sticker" from a WebP; still stickers as WebP to keep transparency;
  memes as PNG/JPG). The Studio has search + share for all three. Each kind has its own icon (GIF frame,
  peeled sticker, captioned laughing face) on the bottom-bar tabs and the Studio chips.
  "Powered by KLIPY" is shown wherever KLIPY content appears. Ad items are skipped for now. Files for
  sending live in `cache/stickers/` and are deleted after 10 minutes. Recently sent items (links only) are
  kept on the phone for the Recent chip. v0.5.1 swapped Clips back for Memes (KLIPY `static-memes`); AI Emoji stays removed.
  GIF and sticker grids show **moving previews** (animated WebP/GIF, decoded with ImageDecoder on Android 9+, scaled to
  tile size and cached in `cache/store_thumbs/`); older phones show the still first frame.
- **One emoji panel for everything** (`keyboard/EmojiHub.kt`): ABC · 🔍 · Recent · Emoji (1,140, by
  category) · Kaomoji · GIF · Sticker · Meme (icons) · ⌫. Recently used emoji/kaomoji kept on the phone.
- **Search like Gboard**: 🔍 opens "Search KLIPY …" with Recent / Trending / quick chips and **live results**
  above the full keyboard; results refresh 0.4 s after you stop typing and a tap sends straight away.
  Letters typed there go to the search box only, never into the chat.
- **Translate (v0.6)** (`keyboard/VoiceTranslateUi.kt`, `store/TranslateApi.kt`): 文A in the toolbar opens a
  translate bar like Z Sri's: ✕ · "සිං → En" (tap to swap) · ✓ Translate, with the box underneath. Type
  normally — Singlish still turns into Sinhala, with suggestions — then tap ✓ Translate (or enter): it shows
  "Translating…", types the result into the chat at the cursor and empties the box for the next sentence.
  One request per tap (not live), so normal use stays inside the free allowance. Uses Microsoft Translator
  (free 2M chars/month) or Google Cloud Translation, because ML Kit's on-device translator has no Sinhala.
  Only the translate box text is sent. The provider's attribution is shown.
- **Voice typing (v0.6)** (`ime/VoiceTyping.kt`, `ui/VoicePermissionActivity.kt`): 🎤 opens a voice panel
  that listens straight away with the phone's speech service — `si-LK` in Sinhala, `en-US` in English (the
  globe button switches). Words show as they're heard and are committed when you stop; in translate mode they
  go into the translate box. First use opens an invisible screen for the microphone permission.
- **DIY theme studio (v0.10)** (`ui/screens/ThemeStudio.kt`, `keyboard/CustomTheme.kt`): Themes → **DIY**.
  Sections: Background (14 solids / gradients) · Keys (solid or glass colours, shape Square / Rounded / Soft /
  Pill, outline) · Text & accent (with a readability warning) · Photo (your own picture, copied into the app
  at ≤1600 px, never uploaded; darken 0–80 %, blur None / Soft / Strong — blur by downscale + filtered
  upscale, so it works on Android 7+). Every change shows live in the preview; **Apply** saves "My theme"
  (`themeId = "custom"`, JSON in `customTheme`) and replaces a downloaded background, like built-in themes.
  It starts from your current theme. The selected swatch gets an accent outline and ✓.
- **Phase 3 (v0.9)**:
  - **Emoji style** (`store/EmojiStyles.kt`, Tools → Look & feel): Phone default, **Google (Noto)**, **Twemoji**
    or **OpenMoji** — free, openly licensed sets only (Apple / Samsung / Facebook / Microsoft are copyrighted).
    Images load as you browse (jsDelivr; unpkg / GitHub backups), are cached in app storage, and "Download 3 MB"
    saves a whole set for offline use. File names were checked against emoji-datasource 16.0.0 and OpenMoji
    17.0.0 data for all 1,136 emoji in the panel. Only the keyboard's look changes; chats get normal emoji.
    Credits shown in the panel: Noto (Apache 2.0), Twemoji (CC BY 4.0), OpenMoji (CC BY-SA 4.0).
  - **Floating keyboard** (`keyboard/Floating.kt`, Tools → Floating): the keyboard becomes a card you drag
    anywhere (handle bar: ⇔ width 70/85/100 %, drag the middle, ⤓ dock). The IME window fills the screen but
    `onComputeInsets` limits touches to the card and tells the app nothing covers it (no resizing), like Gboard.
    Position and width are remembered. One-hand mode is ignored while floating.
- **Phase 2 tools (v0.8)**:
  - **Secret text** (`core/engine/SecretText.kt`): lock the selected text / current line with a 4–8 digit PIN →
    `🔐SX1:…` (AES-256-GCM, key = PBKDF2-HMAC-SHA256 60k rounds, own Base64url so it works on Android 7).
    Unlock reads the selection, the clipboard or the text before the cursor; the message is shown only inside

  - **Phrase studio** (`keyboard/PhraseData.kt`): ready Sinhala phrases (Greetings, Wishes, Love, Thanks,

  - **Undo / Redo**: word-by-word undo of what SinhalaX put in (word + space, suggestion, emoji, paste,
    shortcut, voice). Falls back to the app's own undo (Ctrl+Z) when there's nothing safe to take back.
    Pin ↶ to the toolbar; also in Text edit.
  - **Slide gestures** (setting, on by default): slide on space to move the cursor (shows ◀ ▶); slide left
    on ⌫ to select whole words, let go to delete them (shows ⌫ 2…). With it on, a ⌫ tap deletes on release.

  SinhalaX screens (Settings, Themes, Studio, Shortcuts, Privacy, Guide) via `MainActivity.EXTRA_OPEN`.
  - **Text edit**: ▲▼◀▶, ◀ word / word ▶, ⇤ Start / End ⇥, **Select** mode (moves extend the selection),
    Select all, Copy, Cut, Paste, Undo / Redo (the app's own Ctrl+Z).
  - **One-hand**: keys shrink to 82% on one side; ⇄ switches side, ⤢ goes back to full width.
  - **Number pad**: big 0–9 with + − , * # . for OTPs, phone numbers and USSD codes.
  - **Shortcuts**: `gm` + space → "සුභ උදෑසනක්! ☀️" (works in Sinhala and English mode; shows as the first
    suggestion; backspace right after puts the code back). Managed in the app (Settings → Tools → Manage

  - **Calculator** (`core/engine/Calculator.kt`): + − × ÷ % ( ), live answer, **Insert** puts the answer

### KLIPY API key
Put your key in `local.properties` (already git-ignored), then sync/rebuild:
```
KLIPY_API_KEY=your_key_here
```
It becomes `BuildConfig.KLIPY_API_KEY`. Without it the sticker screens show a "not set up" message.
Before release, move the key from TESTING to production in the KLIPY Partner dashboard.

### Translation key (pick one)
Translate needs one online key because no on-device translator has Sinhala.

**Recommended: Microsoft Translator** — free tier 2,000,000 characters/month (Google's is 500,000).
1. Azure portal → Create resource → **Translator** → pricing tier **F0 (free)**; note the region.
2. Keys and Endpoint → copy KEY 1. Add to `local.properties`:
```
AZURE_TRANSLATOR_KEY=your_key_here
AZURE_TRANSLATOR_REGION=southeastasia
```
(Leave out the region line if you chose "Global".) When this key is set it's used; the status line shows
"Translated by Microsoft".

**Or Google Cloud Translation** (used only when no Microsoft key is set):
1. Google Cloud Console → enable **Cloud Translation API** (billing on; the first 500,000 characters a month
   are free, then about US$20 per million characters).
2. Credentials → create an API key → **Application restrictions: Android apps**, package
   `dev.valhalla.sinhalax`, and add the SHA-1 of every signing key (debug, upload, and the **Play App Signing**
   key from Play Console → Setup → App signing). **API restrictions:** Cloud Translation API only.
3. Add it to `local.properties`:
```
GOOGLE_TRANSLATE_API_KEY=your_key_here
```
It becomes `BuildConfig.GOOGLE_TRANSLATE_API_KEY`; the app sends `X-Android-Package` / `X-Android-Cert` so the
restriction works. Without a key the translate box shows a "needs a key" message. (Later you can route this
through your own server instead, so the key never ships in the APK.)

### Play Console data safety (v0.6)
- **Audio — Voice or sound recordings**: voice typing. Processed by the phone's speech service, not kept by the
  app. Mark as *not collected* by the app only if you're sure your form's definitions agree; otherwise declare
  it as processed ephemerally, not shared, optional.
- **Messages / App activity — Other user-generated content**: translate box text, sent to Microsoft
  Translator or Google Cloud Translation to get the translation (shared with a service provider), ephemeral, optional.
- The `RECORD_AUDIO` permission needs the in-app explanation (Security & privacy → Voice typing).
